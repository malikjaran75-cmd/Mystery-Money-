Mystery Money Membership — Android Deploy Kit

This package is the current front-end demo prepared for a GitHub -> Vercel deployment from an Android phone.
Read ANDROID-SETUP-HINDI.txt before uploading.

The live deployment from this package is still a demo only. It uses browser localStorage and demo login flows.
It is NOT safe for real payments, real customer information, or live merchant redemptions until a secure backend,
OTP, OAuth, payment verification, database access policies, and production testing are implemented.

Membership defaults in this demo:
Silver ₹101, Gold ₹251, Platinum ₹501, Diamond ₹1,001; 30-day validity.
Discount uses the lower of the shop offer and membership tier allowance; it does not add discounts.
Membership code can be redeemed repeatedly while active in this demo; each redemption is logged locally.
